# Recipe Explorer 🍽️

A responsive recipe search application built with Vanilla JavaScript, Bootstrap 5, and TheMealDB API.

## ✨ Features

- Search for recipes by name.
- Browse recipe cards with images and names.
- View detailed recipe information.
- Display ingredients and measurements.
- Handle loading, error, and empty search results.
- Responsive layout for different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- Fetch API
- TheMealDB API
- Vite

## 🚀 Getting Started

### Prerequisites

- Node.js and npm installed on your machine.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YousefAmgad0/recipe-explorer.git
   ```

2. Navigate to the project directory:

   ```bash
   cd recipe-explorer
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.

## 🏗️ Production Build

To create a production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## 🌐 API

Recipe data is provided by [TheMealDB](https://www.themealdb.com/api.php).
